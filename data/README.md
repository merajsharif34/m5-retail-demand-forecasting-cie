# Data

Raw datasets are intentionally **not included** in this GitHub repository.

## M5 Forecasting Accuracy

The primary empirical source is the M5 Forecasting Accuracy competition dataset. Obtain the competition data from its original distribution and configure the notebook's input path accordingly.

## DataCo SMART SUPPLY CHAIN

DataCo is used only as an external robustness/validation dataset. The manuscript identifies the public Mendeley Data record:

DOI: `10.17632/8gx2fvg2k6.5`

## Why raw data are excluded

The repository should remain lightweight and reproducible without redistributing large competition data files. Never commit credentials, private datasets, or local Kaggle files.
